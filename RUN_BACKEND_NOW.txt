╔══════════════════════════════════════════════════════════════════════════════╗
║                           ❓ TROUBLESHOOTING                                 ║
╚══════════════════════════════════════════════════════════════════════════════╝

   Problem: "dotnet: command not found"
   Solution: Install .NET 8.0 SDK from https://dotnet.microsoft.com

   Problem: "Cannot connect to SQL Server"
   Solution: 
   - Check SQL Server service is running
   - Open Services (services.msc)
   - Find "SQL Server (MSSQLSERVER01)"
   - Make sure it's running

   Problem: "Port 2780 already in use"
   Solution:
   - Kill the process using that port
   - Or change port in Properties/launchSettings.json

   Problem: "Database error"
   Solution:
   - Check connection string in appsettings.json
   - Make sure Windows Authentication works
   - Try connecting via SQL Server Management Studio first
