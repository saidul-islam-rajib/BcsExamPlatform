STEP 1: MOVE FLUTTER FOLDER
═══════════════════════════════════════════════════════════════
Your Downloads/Desktop
    └── flutter (extracted folder)
              ↓
              ↓ COPY & PASTE
              ↓
    C:\
    └── flutter
        └── bin
            └── flutter.bat  ← This is what we need!

✅ Final location: C:\flutter

═══════════════════════════════════════════════════════════════

✅ Flutter is now in PATH!


STEP 3: VERIFY INSTALLATION
═══════════════════════════════════════════════════════════════
Open NEW Command Prompt or PowerShell:

    C:\> flutter --version

Expected output:
    ┌─────────────────────────────────────┐
    │ Flutter 3.x.x • channel stable      │
    │ Framework • revision xxxxx          │
    │ Engine • revision xxxxx             │
    │ Tools • Dart 3.x.x                  │
    └─────────────────────────────────────┘

✅ If you see this → SUCCESS!
❌ If "not recognized" → Restart terminal and try again


STEP 4: RUN FLUTTER DOCTOR
═══════════════════════════════════════════════════════════════
    C:\> flutter doctor

Output will show:
    ┌─────────────────────────────────────┐
    │ [✓] Flutter                         │
    │ [✗] Android toolchain               │
    │ [✗] Chrome                          │
    │ [✗] Android Studio                  │
    │ [✗] VS Code                         │
    └─────────────────────────────────────┘

Don't worry about ✗ marks! We'll fix them.


STEP 5: INSTALL GIT (REQUIRED)
═══════════════════════════════════════════════════════════════
1. Go to: https://git-scm.com/download/win
2. Download "64-bit Git for Windows Setup"
3. Install with default settings (keep clicking Next)

Verify:
    C:\> git --version
    git version 2.x.x

✅ Git installed!


STEP 6: TEST YOUR BCS APP
═══════════════════════════════════════════════════════════════
Navigate to your project:

    C:\> cd C:\Users\User\Desktop\BCS\mobile

Get dependencies:

    C:\Users\User\Desktop\BCS\mobile> flutter pub get

Expected:
    ┌─────────────────────────────────────┐
    │ Running "flutter pub get"...        │
    │ Resolving dependencies...           │
    │ ✓ Got dependencies!                 │
    └─────────────────────────────────────┘

Run on Chrome (easiest):

    C:\Users\User\Desktop\BCS\mobile> flutter run -d chrome

✅ Your app opens in Chrome!


OPTIONAL: ANDROID STUDIO (FOR ANDROID DEVELOPMENT)
═══════════════════════════════════════════════════════════════
Only if you want to test on Android:

1. Download: https://developer.android.com/studio
2. Install with default settings
3. Wait for SDK download (10-20 minutes)
4. Create virtual device (emulator)

Then run:
    C:\> flutter doctor --android-licenses
    (Type 'y' for all)

    C:\> flutter run -d android

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════
Problem: "flutter is not recognized"
Solution: 
    1. Check C:\flutter exists
    2. Check PATH has C:\flutter\bin
    3. RESTART terminal (important!)
    4. Try again

Problem: "pub get failed"
Solution:
    flutter clean
    flutter pub get

Problem: "No devices available"
Solution:
    flutter run -d chrome  (use Chrome, no setup needed)
